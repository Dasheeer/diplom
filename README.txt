Презентация диплома лежит в папке
----------------------------------------------------------
Инструкция по запуску системы мониторинга MoniQ:

1. Установите Python 3.11 или выше.
2. Установите библиотеки:
   pip install -r requirements.txt

3. Запустите файл:
   python app.py

4. Перейдите в браузере по адресу:
   http://127.0.0.1:5000

⚠️ Для работы необходим интернет (если используется Firebase).

окружение:
rmdir /s /q venv
python -m venv venv
